# R-020 — Key export + Ed25519/ECDSA generation (K-03/K-05)

## Findings

**K-05 (key gen)**: `KeyGeneratorScreen` was hard-coded to RSA-3072 PKCS#8. No algorithm choice.
**K-03 (export)**: `IdentityEditScreen` showed public key in `SelectionContainer` with clipboard-only copy. No file export for private key.

Ed25519: `KeyPairGenerator.getInstance("Ed25519", "BC")` — BouncyCastle already in project.
ECDSA P-256: `KeyPairGenerator.getInstance("EC", "BC").apply { initialize(ECGenParameterSpec("secp256r1")) }`.
Private key serialized with `JcaPEMWriter` (BouncyCastle).

## Implementation

### `KeyGeneratorScreen.kt` (rewritten)
- `KeyAlgorithm` enum: `RSA_3072`, `ED25519`, `ECDSA_P256`.
- `ExposedDropdownMenuBox` algorithm selector.
- Generation per algo: RSA from JCA; Ed25519/ECDSA via `"BC"` provider.
- PEM written with `JcaPEMWriter`.
- Public key encoding unchanged (sshj `Buffer.PlainBuffer().putPublicKey`).

### `IdentityEditScreen.kt` — private key file export
- `exportKeyLauncher = rememberLauncherForActivityResult(CreateDocument("application/x-pem-file"))`.
- On confirm: reads PEM from `CredentialStore.getPrivateKey(identityId)`, writes to chosen URI.
- Button "Save private key to file…" shown after "Check key" succeeds (alongside clipboard button).
