# R-021 — Full SFTP operations: mkdir, rename, delete (SF-01)

## Findings

`SshEngine` had: `listFiles`, `canonicalPath`, `download`, `upload` (with EXCL flag).
Missing: `mkdir`, `rename`, `rm`, `rmdir`. SSHJ `SFTPClient` supports all of these.
`SftpBrowserScreen` had: listing, nav, download, upload-dialog. No mkdir/rename/delete.

## Implementation

### `SshEngine.kt` — new SFTP wrappers
- `suspend fun mkdir(path)` → `sftp.mkdir(path)`
- `suspend fun rename(oldPath, newPath)` → `sftp.rename(oldPath, newPath)`
- `suspend fun rm(path)` → `sftp.rm(path)`
- `suspend fun rmdir(path)` → `sftp.rmdir(path)`

### `SftpBrowserScreen.kt` (rewritten)
- FAB with `CreateNewFolder` icon → mkdir dialog.
- Long-press on `ListItem` → `ModalBottomSheet` with Rename / Delete options.
- Rename: dialog with new-name field → `engine.rename(entry.path, newPath)`.
- Delete: confirm dialog → `engine.rm(path)` or `engine.rmdir(path)` based on `entry.directory`.
- `combinedClickable(onClick, onLongClick)` replaces plain `clickable`.
- `op{}` helper replaces `transfer{}` for all mutating operations; refreshes listing on success.
- Error messages shown inline.

chmod deferred: `RemoteEntry` doesn't expose permissions; needs `SftpBrowserScreen` + `SshEngine` additions.
