## Behavior contract and LimeSSH mapping

**Ctrl toggle**: state `ctrlArmed: Boolean`. When Ctrl button tapped: `ctrlArmed = true` (button highlighted). When next soft-key button pressed: byte sequence is the key's byte AND 0x1F; then `ctrlArmed = false`. Hardware keyboard Ctrl is unaffected (handled by `onKeyEvent`).
**Alt/Esc toggle**: state `altArmed: Boolean`. When Alt button tapped: send `0x1B` immediately; `altArmed = true` (highlighted). No further modification — ESC prefix is already sent. Reset on next key. (Sends ESC, then key, not `ESC key` as a combined unit — matching JuiceSSH observed behavior.)
**New static keys**: `|` → `0x7C`, `~` → `0x7E`, PgUp → `ESC[5~`, PgDn → `ESC[6~`, F1 → `ESC OP`, F2 → `ESC OQ`, F3 → `ESC OR`, F4 → `ESC OS`.
